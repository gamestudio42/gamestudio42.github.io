03 / NOTRE FAÇON DE CRÉER

Fait pour jouer.
Ouvert aux possibles.

Nous créons des mondes où les décisions laissent une trace : un canal fait vivre un quartier, une route ravitaille une escouade, un bloc devient un abri. Chez Game Studio 42, la simulation est le point de départ du jeu. Beaucoup de jeux s’ouvrent instantanément dans le navigateur ; certains sortent aussi en applications de bureau. Chaque système reste ouvert à la découverte et à la transformation.

Créé ensemble, au grand jour.

Game Studio 42 associe création indépendante et collaboration ouverte. Derrière chaque jeu, des personnes écrivent du code, dessinent des mondes et soignent les détails. Jouez, partagez une idée ou contribuez à la prochaine version.

04 / GRANDIR AVEC LA COMMUNAUTÉ

Votre projet peut grandir avec Game Studio 42.

Proposez votre jeu open source ou votre technologie pour les jeux : moteurs, frameworks, bibliothèques, SDK, outils et agents IA. Tous les moteurs. Toutes les plateformes.

Reprise communautaire

Un dépôt dans l’organisation et une collaboration partagée après approbation. La promotion dans le catalogue est évaluée séparément.

Des repères clairs, une place pour chaque projet.

Nous privilégions AGPL-3.0-or-later pour les jeux et serveurs multijoueurs, et Apache-2.0 pour les technologies réutilisables. Les licences MIT, BSD, GPL et autres licences open source sont également évaluées. Les exceptions sont documentées ; l’accueil n’exige aucun changement automatique de licence. Les projets existants conservent leurs licences.
